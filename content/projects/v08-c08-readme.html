Tern Thermal Systems: real-options laboratory

Return to the chapter. All four proposals are original fictional teaching cases, with amounts in thousands of currency units and dates 0, 1 and 2 separated by one year. They are separate proposals and must not be added into a company value. No network, packages, actual market data or private credentials are used.

Run and reproduce

Save the program and the inputs together. Run python3 v08-c08-analysis.py, or supply the path of an edited input file as its first argument. Reference output supplies exact fractions and decimals. Use integer values or strings for decimals and fractions; binary floating-point input is deliberately rejected. Importing the module performs no file writes.

Model boundaries and timing

  • Delay: only this case uses a traded clone and no-arbitrage replication. Both physical states must remain possible, so physical_up lies strictly between zero and one. Within that domain it changes forecast returns, not the price given the unchanged clone and bond. The interim receipt belongs only to immediate investment and adds to that package's current value.
  • Operations: the linear owner's criterion discounts expected money at 5%. Remaining values, expansion expenditure and net salvage are all date-1 values. The owner observes the state before choosing. Expansion and abandonment are mutually exclusive; funding capacity can exclude expansion. Ties select the first listed maximizing action without changing value.
  • Stage: pay for the pilot now. Observe validation before deciding whether to pay scale-up at date 1. Receive final cash at date 2. The stopping rule applies in each state, including any edited failure receipt. The reported probability threshold is supplied only when validated continuation is positive and failed continuation is nonpositive; a threshold above one means no feasible success probability suffices.
  • Information: compare launch or rejection at the same date 1 with or without the report. The report fee is paid at date 0. Update physical beliefs by Bayes' rule, decide after the report, discount once more to date 0. The report changes information only. Zero-probability signals are marked unreachable rather than divided by zero. A posterior threshold outside [0,1] means launch is always or never worthwhile over attainable beliefs.

Useful variations

Set the delay interim receipt to 10. Reduce available expansion cash to 30. Change validation probability around 363/1175. Give the report identical positive likelihoods under good and bad demand; its gross information value should become zero. Raise the report fee to 3 and compare with the best no-report policy. Do not relabel owner decision values as market values: the program has no market pricing model for those risks.

The root checker separately reconstructs the replicated payoffs, enumerates feasible actions and signal policies, recomputes the exercise answers, and checks selected invalid-input and funding/information boundaries. These checks establish internal consistency of the stipulated models, not the accuracy of a real forecast or the availability of an actual right.
