VOLUME 18 — JOINT LEADERSHIP REHEARSAL

These five downloadable files are a self-contained standard-library Python
package. All institutions, people, work samples, dates, transactions and feedback
are invented. They depict some completed actions inside fiction; they do not
supply the learner's actual responsibility, permission, research, teaching,
customer outcomes or independent human evaluation.

Files
  v18-assessment-inputs.json     complete primitive data and source packet
  v18-assessment-analysis.py    reader model and command-line interface
  v18-assessment-output.json    expected strict-JSON output
  v18-assessment-manifest.json  byte counts/SHA256 of the other four files
  v18-assessment-README.txt     this guide

Execution
  python3 v18-assessment-analysis.py
writes the neighboring v18-assessment-output.json silently. Or use
  python3 v18-assessment-analysis.py INPUT.json NEW-OUTPUT.json
from any current working directory. Python's standard library is sufficient;
no package installation, network call, database, credentials or machine-wide
configuration is needed. The program validates strict JSON, rejecting duplicate
keys and nonfinite values. Exact inputs are integer values or rational strings,
for example "1/2"; booleans are not monetary numbers. Output rationals are
integers when integral and rational strings otherwise. No rounding tolerance
is used in the exact model.

The pure API is run(data), loaded from this script. It returns a new strict-JSON
object, emits no stdout/stderr, never writes and never mutates data. Importing
or loading the module does not run the CLI. Invalid input raises an exception;
checks remain active under python3 -O. An economically valid but infeasible
plan returns false feasibility/reasons or no selected bundle/contract/action.
A control exception is retained even if the closing accounts balance.

Output protection
Before any CLI write, output is compared with the actual selected input and
with inputs/code/README/manifest beside both the script and selected input.
Direct/resolved paths, symbolic links and existing hardlinks to protected
payloads are rejected. The ordinary expected-output file is intentionally
writable. For changed inputs, choose a new output filename: overwriting the
supplied expected output changes the manifest identity. Manifests establish
file identity, not economic truth, authority, consent or reviewer endorsement.

Models and interpretation
ACADEMIC: Enumerate all eight R/T/L subsets. Date-zero fixed payment30 includes
6 already transferred to a payroll provider. Later salary/bonus is paid from
that envelope, not charged to institute cash again; no refund is assumed.
A research-only grant is usable only after receipt and only for R, without an
assumed retroactive reimbursement. Each dated payment uses eligible available
grant cash first; all other spending uses unrestricted cash. Check the minimum
unrestricted balance and total staff, then maximize declared mission score,
with lower total cost/code breaking ties. Model score is not a measured learning
or research outcome. The selected R+T plan delays R to day6 after grant day5.

PEOPLE: Keep both actual submitted work and stipulated criterion ratings.
Rank only complete eligible samples under the written equal-weight rule;
missing scores produce possible bounds, not fabricated zeros. Solve the
strictly concave utility over [0,1], then test output, quality, participation
and the maximum payroll reservation. A unique prediction under stipulated
preferences is not empirical validation of worker behavior.

GOVERNANCE: Apply the invented present-eligible majority and quorum separately.
Interested members cannot be present; yes/no/abstain partition attendance.
Approval scope does not include donor censorship or actual legal clearance.

FINANCE: Replay dated observed events. Actual debt principal reduces cash and
liabilities; expense reduces cash/equity; fee income increases cash/equity.
All securities/loans remain at opening book amounts. Approval is effective only
before the expense and up to its remaining amount. Actual unauthorized spending
is still booked and flagged. Forecast/proposed/missing events do not book cash.
A notification of an already recognized receipt does not book it again.
Every event preserves assets=liabilities+equity; floors and authority exceptions
are separately reported. No tax, regulatory-capital or valuation rule is implied.

CRISIS: Each release is a conditional information packet. Evaluate funded cash,
book equity, staff capacity, setup deadline and action-specific approval before
ranking the stipulated total service-loss values. Loss already includes the
operating cost; do not add it again. The late packet is a counterfactual, not
an additional actual transaction. Changed actual events and release assumptions
must be reconciled by the analyst before making a combined real-world claim.

EVIDENCE: Observed-in-fiction, missing and proposed records remain separate.
The program routes their supplied statuses; it cannot verify observations,
permissions, employment judgments, research originality or causal leadership.
The complete HTML instructor package supplies substantive judgments and proofs.
No automatic sentiment/text scoring or actual evaluator is hidden in the code.

Meaningful variations
Move grant receipt to day7 or R payment to day2; the R/T plan then breaches
the interim unrestricted floor although a final balance can look acceptable.
Reduce opening unrestricted cash below fixed obligations plus reserve; no
expansion subset may be feasible, including none. Raise minimum quality to3/5;
service e>=1/2 and quality1-e>=3/5 are jointly impossible, so no menu contract
passes. Remove Fay from attendance and abstentions; the majority can pass while
quorum fails. Change an actual receipt amount or make it only forecast; the
ledger retains observed payments and flags resulting floor problems. Delay
approval beyond minute15; a15-minute backup cannot meet minute30. Preserve
original and changed runs, and do not promote a scenario to an actual event.

Scoring and actual-work continuation
Seven tasks map to five20-point domains; time/thresholds are proposed and
uncalibrated. Full instructor artifacts are in the project HTML. An actual
learner must secure a permitted role/resource agreement, retain contemporaneous
authority/decision/action/outcome records, obtain real feedback and independent
human evaluation, and defend their own work. The separate leadership portfolio
cross-assessment requires those submissions; this synthetic rehearsal does
not complete them. Inspect real source/access/ethics conditions before any real
project; the fictional policies are not universal institutional rules.
